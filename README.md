# 🧠 Neural Networks and Deep Learning with PyTorch

A comprehensive Deep Learning project implementing and comparing multiple neural network architectures using PyTorch, including MLPs, CNNs, RNNs, LSTMs, GRUs, and Seq2Seq models.

## 🚀 Project Overview

This project explores the design, training, evaluation, and comparison of several Deep Learning architectures across different tasks:

- Binary Classification (Breast Cancer Dataset)
- Image Classification (MNIST)
- Sentiment Analysis (IMDb Reviews)
- Sequence-to-Sequence Learning
- Beam Search Decoding

The objective is to understand the strengths, limitations, and practical applications of each architecture.

---

## 🧠 Implemented Models

### Multi-Layer Perceptron (MLP)
- Breast Cancer Classification
- Xavier Initialization
- Early Stopping
- Model Saving and Loading

### Convolutional Neural Network (CNN)
- LeNet Architecture
- MNIST Digit Recognition
- Feature Map Visualization
- Pooling and Convolution Analysis

### Recurrent Neural Networks
- Vanilla RNN
- LSTM
- GRU
- Gradient Clipping

### Sequence Models
- Seq2Seq Architecture
- Greedy Decoding
- Beam Search
- BLEU Score Evaluation
